# Rakib Hasan Shuvo — Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy
Upload the folder to GitHub Pages, Netlify, or Vercel as a static site.

## Customize
- Replace `assets/profile.jpg` with your latest photo if needed.
- Update the About, skills, projects and contact details in `index.html`.
